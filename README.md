# Robot Lightweight Design

&gt; 材料背景研究生转向机器人轻量化设计的项目合集

## 项目目标
针对人形机器人/协作机械臂，探索轻量化材料（碳纤维、PEEK、镁合金等）在机器人结构中的应用，通过拓扑优化和仿真分析实现减重目标。

## 仓库结构
- `/models` — SolidWorks/Onshape 模型文件
- `/simulations` — ANSYS 仿真报告与结果
- `/notes` — 学习笔记与文献阅读
- `/reports` — 设计报告与对比分析
