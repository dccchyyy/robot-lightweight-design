# Robot Lightweight Design

&gt; 材料背景研究生转向机器人轻量化设计的项目合集

## 项目目标
针对人形机器人/协作机械臂，探索轻量化材料（碳纤维、PEEK、镁合金等）在机器人结构中的应用，通过拓扑优化和仿真分析实现减重目标。

## 仓库结构
- `/models` — SolidWorks/Onshape 模型文件
- `/simulations` — ANSYS 仿真报告与结果
- `/notes` — 学习笔记与文献阅读
- `/reports` — 设计报告与对比分析

## 快速预览

### 三种材料对比结果（轴向载荷 50N，空心管 44,000 mm³）

| 材料 | 质量(g) | 相对铝减重 | 最大变形(μm) | 刚度评价 |
|------|---------|------------|--------------|----------|
| 6061-T6铝 | 118.8 | 基准 | 0.66 | 中等 |
| T300碳纤维 | 70.4 | -40.7% | 0.197 | 最高 |
| AZ91D镁合金 | 79.6 | -33.0% | 1.004 | 较低 |

**工程结论：**
- 追求极致刚度 → 选碳纤维（轻41%，变形最小）
- 追求性价比减重 → 选镁合金（轻33%，可铸造成型）
- 通用场景 → 铝合金（工艺最成熟）

详细分析见 `/notes/报告/轻量化连杆材料对比分析.md`
