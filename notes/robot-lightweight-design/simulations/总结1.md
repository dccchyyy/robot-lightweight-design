# 机器人轻量化连杆设计项目总结

## 1. 项目目标

本项目以机器人连杆为对象，完成一个基础的轻量化结构设计与有限元仿真流程。

核心目标：

1. 建立机器人连杆三维模型；
2. 对连杆进行逐步轻量化设计；
3. 使用 FreeCAD FEM + CalculiX 对结构进行静力学分析；
4. 比较不同结构方案的质量、应力与变形；
5. 通过 ANSYS 进行补充仿真练习；
6. 完成“设计 → 仿真 → 优化 → 验证”的完整工程流程。

---

# 2. 设计演进

## V1：初始实心连杆

V1 为初始实心结构，作为轻量化设计的基准。

- 体积：60,000 mm³
- 材料：铝合金
- 密度：2.70 g/cm³
- 质量：162.0 g

V1 的主要作用是建立基准模型，为后续结构减重提供参照。

---

## V2：空心化设计

在 V1 基础上进行内部材料去除，形成 V2 空心结构。

### V2 参数

- 体积：44,000 mm³
- 质量：118.8 g
- 相对 V1 减重：26.7%

### FreeCAD FEM 仿真结果

仿真工况：

- 材料：铝合金
- 弹性模量：约 69 GPa
- 泊松比：0.33
- 密度：2700 kg/m³
- 一端固定
- 另一端施加 50 N 轴向载荷

结果：

| 指标 | V2 |
|---|---:|
| 最大 von Mises 应力 | ≈ 0.245 MPa |
| 最大位移 | ≈ 0.66 μm |
| 质量 | 118.8 g |

V2 在明显减轻质量的同时，应力和变形仍然较小，因此具备进一步轻量化的空间。

---

# 3. V5：开孔轻量化优化

## 3.1 最终结构方案

在 V2 基础上进一步进行材料去除。

最终采用：

- 椭圆形通孔
- 长轴：30 mm
- 短轴：14 mm
- 通孔贯穿连杆厚度

之前曾尝试更大的椭圆孔，但由于孔边剩余材料过薄，导致 Gmsh 无法生成质量可靠的三维体网格，因此最终缩小开孔尺寸。

---

## 3.2 V5 最终几何数据

V5 最终体积：

**35,158.18 mm³**

铝合金质量：

**约 94.93 g**

### 减重效果

| 版本 | 体积 / mm³ | 质量 / g | 相对 V1 减重 |
|---|---:|---:|---:|
| V1 | 60,000 | 162.0 | 基准 |
| V2 | 44,000 | 118.8 | 26.7% |
| V5 | 35,158.18 | 94.93 | **41.4%** |

V5 相比 V2：

**进一步减重约 20.1%。**

因此最终结构质量由：

**162.0 g → 94.93 g**

整体减重约：

**41.4%。**

---

# 4. V5 有限元仿真

## 4.1 网格

使用：

**FreeCAD FEM + Gmsh**

最终采用三维实体网格：

- 3D tetrahedral mesh
- 一阶四面体单元
- 节点约 7,659
- 三维体单元约 24,301

最终确认网格内部存在 Volume Elements，可以用于 CalculiX 实体结构求解。

---

## 4.2 边界条件

V5 与 V2 保持相同基本仿真工况：

- 右端固定；
- 左端施加 50 N 轴向载荷；
- 铝合金材料；
- 线弹性静力分析。

重新建立 V5 网格后，对固定端和加载端重新进行了确认，以避免由于模型几何变化导致 Face 编号改变。

---

# 5. V5 仿真结果

## 等效应力

最大 von Mises 应力：

**2.462 MPa**

最大应力主要集中在开孔附近。

这符合开孔结构的典型力学特征：

> 开孔导致有效承载截面积下降，并在孔边产生局部应力集中。

## 总位移

最大位移：

**1.716 × 10⁻⁶ m**

即：

**0.001716 mm = 1.716 μm**

位移从固定端向受力端逐渐增加，整体变形趋势符合轴向受力条件。

# 6. V2 与 V5 对比

| 指标 | V2 | V5 | 变化 |
|---|---:|---:|---:|
| 体积 / mm³ | 44,000 | 35,158.18 | ↓ 20.1% |
| 质量 / g | 118.8 | 94.93 | ↓ 20.1% |
| 最大应力 / MPa | ≈0.245 | ≈2.462 | ↑ |
| 最大位移 / μm | ≈0.66 | ≈1.716 | ↑ |
| 相对 V1 减重 | 26.7% | **41.4%** | 优化 |

V5 在继续降低质量的同时，应力和位移均有所增加。

这种变化符合轻量化设计的基本规律：

**材料减少  
→ 有效承载截面积下降  
→ 局部刚度下降  
→ 应力集中增强  
→ 变形增加**

因此轻量化并不是简单追求“材料越少越好”，而是在：

**质量、强度、刚度之间寻找平衡。**

---

# 7. V5 方案评价

虽然 V5 最大应力较 V2 明显增加，但其绝对值仅约：

**2.462 MPa**

在当前 50 N 轴向静载工况下，该应力水平仍然较低。

因此，本轮优化可以认为实现了：

> 在保持较大静强度裕量的情况下，通过局部开孔将结构相对于初始 V1 减重约 41.4%。

同时，相比 V2：

> V5 进一步减重约 20.1%，但代价是应力集中和整体变形增加。

因此 V5 比 V2 更能体现真实工程轻量化设计中的性能权衡。

# 8. ANSYS 补充仿真

本项目中还进行了 ANSYS Mechanical 仿真练习。

曾建立 50 N 横向载荷工况，得到：

- 最大 von Mises 应力约：20.87 MPa
- 最大位移约：0.807 mm

该工况属于悬臂梁横向弯曲，与 FreeCAD 中用于 V2/V5 对比的轴向载荷工况不同。

因此：

**ANSYS 结果不直接参与 V2/V5 定量对比。**

其主要作用为：

1. 熟悉 ANSYS Mechanical 基础操作；
2. 理解轴向载荷与横向弯曲工况的区别；
3. 练习材料、网格、固定支撑、力载荷以及结果后处理流程。

# 9. 本项目中的关键问题与排错

## 9.1 V5 最初出现“结果与 V2 完全一致”

第一次 V5 求解得到：

- 应力约 0.245 MPa
- 位移约 0.656 μm

结果与 V2 几乎完全一致。

进一步检查发现：

**实际仍然使用了 V2 的旧 FEM 网格。**

因此该结果被判定为无效。

### 经验

修改 CAD 几何后，不能仅复制旧 Analysis。

必须重新确认：

- Mesh 是否对应新几何；
- Fixed Constraint 是否仍指向正确端面；
- Force Constraint 是否仍指向正确端面；
- Results 是否为本次新求解结果。

---

## 9.2 FEM mesh has no volume elements

曾出现：

> FEM mesh has no volume elements

原因：

Gmsh 只成功生成了表面三角形单元，没有生成三维四面体体单元。

随后检查模型发现：

- 几何中存在 Compound；
- 大尺寸椭圆孔产生极窄区域；
- Gmsh 难以生成稳定的三维实体网格。

---

## 9.3 Gmsh 出现大量 ill-shaped tetrahedrons

大椭圆孔方案中一度出现：

> 340 ill-shaped tets

说明孔边局部几何过于尖锐或剩余材料过薄。

最终没有继续通过调整网格参数强行求解，而是：

**重新修改结构本身。**

将椭圆孔改为：

**30 mm × 14 mm**

随后成功生成约：

**24,301 个三维体单元**

并完成 CalculiX 求解。

### 经验

> 网格问题有时本质上是结构设计问题。

工程优化不能只靠调网格参数解决。

# 10. 项目最终结论

本项目完成了机器人连杆由初始结构到轻量化结构的两轮优化。

设计演进：

**V1 实心结构  
→ V2 空心化  
→ V5 局部开孔优化**

最终实现：

- 质量：162.0 g → 94.93 g
- 总体减重：约 41.4%
- 最大应力：约 2.462 MPa
- 最大位移：约 1.716 μm

在当前 50 N 轴向静载工况下，V5 仍具有较大的静强度裕量。

本项目最终形成了一个完整的小型工程设计闭环：

**CAD 建模  
→ 材料定义  
→ FEM 网格  
→ 边界条件  
→ CalculiX 求解  
→ 结果分析  
→ 发现问题  
→ 修改结构  
→ 重新仿真  
→ 方案比较**
