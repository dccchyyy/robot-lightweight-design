# 项目：轻量化机械臂连杆设计

## 1. 设计目标
设计一根机器人机械臂连杆，在满足强度和刚度要求的前提下，实现最大化减重。

## 2. 设计约束
- 长度：200 mm
- 截面：矩形空心管（初步）
- 载荷：末端承受 50N 垂直力
- 固定方式：一端完全固定（法兰连接）

## 3. 候选材料
| 材料 | 密度(g/cm³) | 弹性模量(GPa) | 屈服强度(MPa) | 优缺点 |
|------|-------------|---------------|---------------|--------|
| 6061铝合金 | 2.70 | 69 | 276 | 基准方案，易加工 |
| T300碳纤维 | 1.60 | 230 | 1500 | 减重明显，各向异性 |
| AZ91D镁合金 | 1.81 | 45 | 230 | 比强度高，耐腐蚀差 |

## 4. 设计流程
1. 建立参数化模型（FreeCAD）
2. 静力学仿真（FreeCAD FEM / ANSYS）
3. 对比分析（应力、变形、质量）
4. 拓扑优化（可选）
5. 输出设计报告

## 5. 预期产出
- FreeCAD 模型文件（.FCStd）
- 仿真报告（含应力云图、变形云图）
- 材料对比表格
- GitHub 项目 README 更新
